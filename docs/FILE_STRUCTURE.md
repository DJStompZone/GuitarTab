# GuitarTab File Structure

Reference guide for the key folders, scripts, and documents that make up the GuitarTab repository. Use the tree below to orient yourself and quickly reach the asset you need.

## High-Level Tree

```
GuitarTab/
├── configs/     # For hydra
│   ├── config.yaml - Main entry point
│   ├── data/
│   ├── model/
│   └── training/
├── data_splits/   # Generated by scripts/split_files.py
│   ├── train_files.json
│   ├── val_files.json
│   └── test_files.json
├── docs/
│   ├── OUTPUT_FORMAT.md - Output format (v1/v2) configuration guide
├── DadaGP-v1.1/
├── notebooks/
├── outputs/
├── papers/    # markdown generated from paper with ChatGPT
├── scripts/
│   ├── generate_selected_files.py
│   └── split_files.py
├── src/
│   ├── dadagp.py   # copied from dadaGP
│   ├── token_splitter.py  # copied from
│   ├── dadagp_parser.py   # dadaGP -> token
│   ├── metrics.py
│   ├── model.py
│   ├── tab_dataset.py   # event -> token, split to segments, collate function
│   ├── visualization.py    # visualize token as tab
├── inference.py
├── train.py
├── selected_files.json   # generated by `generate_selected_files.py`
├── test_*.py  # one-time code for checking some logics
```
