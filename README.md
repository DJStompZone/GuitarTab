## Dataset Selection
```
python get_dataset.py
```
Use `get_dataset.py` to select only one-track and 6-string guitar gp files. 

Total select 5185 gp files.

## Pre-processing 
- gp2jams
- jams2midi
 
First stage: Convert gp files to jams files
```
cd gp2jams
python process_guitrapro.py
```
Change the `gpro_dir` parameter in `process_guitrapro.py` for your download DadaGP dataset folder name.

Second stage: Convert jams files to midi files
```
cd jams2midi
bash jams2midi.sh
```
Change the dir name you set in bash `python JAMS-to-MIDI.py <targetDir> <outputDir> <keyswitch_config>`

Final get the 14751 midi files.

## Train
```bash
# DadaGP + Leduc combined (recommended)
python train.py data=combined

# Leduc only
python train.py data=leduc

# DadaGP only
python train.py data=dadagp

# Shortcut
bash scripts/train.sh
```
The training log and checkpoint will save in `outputs/` folder.

For HPC cluster (SLURM), edit `run_train.sh` and submit:
```bash
sbatch run_train.sh
```

## Inference & Evaluate
Evaluate on both DadaGP and Leduc test sets at once:
```bash
bash scripts/inference.sh outputs/<exp_dir>/best_model.pt
```

Or evaluate a single test set:
```bash
# DadaGP test set
python inference.py data=dadagp \
  +checkpoint_path=outputs/<exp_dir>/best_model.pt

# Leduc test set
python inference.py data=leduc \
  "data.selected_files_json=10984521/FrancoisLeducDatasetPublication/FrancoisLeducDatasetPublication/test_files.json" \
  +checkpoint_path=outputs/<exp_dir>/best_model.pt
```

Metrics reported:
- Token accuracy
- Pitch accuracy
- Tab accuracy

Inference saves `predictions.pt`, `targets.pt`, `input_ids.pt`, `segment_sources.json` to `outputs/<exp_dir>/`.

## Demo (Audio / MIDI → Tab)
Run on a single audio or MIDI file and get ASCII tablature + MIDI output:
```bash
python demo.py \
  --input "Demo/my_song.mp3" \
  --checkpoint outputs/<exp_dir>/best_model.pt \
  --max-bars 8 \
  --output "Demo/my_song_tab.txt" \
  --output-midi "Demo/my_song.mid"
```

Supports `.mid`, `.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a`.
Audio input requires: `pip install basic-pitch onnxruntime`

> **Note (VS Code Remote):** `--play` plays audio on the remote server. Download the generated `.mid` file locally to listen.

## Visualize Tab as Image
Render inference results as PNG guitar tablature images:
```bash
python visualize_song.py \
  --output-dir outputs/<exp_dir> \
  --segment 0 \
  --show both
```

Arguments:
- `--segment`: Segment index to render (use `segment_sources.json` to find which song it belongs to)
- `--show`: `pred` (prediction only), `gt` (ground truth only), or `both`
- `--bars-per-row`: Number of bars per row (default: 4)
- `--out`: Custom output PNG filename (optional)

PNG files are saved to `outputs/<exp_dir>/tab_pred_seg0.png` and `tab_gt_seg0.png`.
The title shows the artist name read from `segment_sources.json`.

## Post-processing
Apply post-processing on predictions generated by `inference.py` to improve fret assignment.

### Methods
- `fret` — re-assigns frets using a voicing heuristic
- `reverse` — reverses string order for alternative voicing

### Example
```bash
python archive/python/run_post_processing.py \
    --output-dir outputs/inference_folder \
    --method reverse \
    --output-format v1
```

> Post-processing scripts are in `archive/python/`. See [docs/POST_PROCESSING_GUIDE.md](docs/POST_PROCESSING_GUIDE.md) for details.

## DadaGP Dataset
### Token
```
artist:unknown_artist
downtune:0
tempo:100
start
new_measure
clean0:note:s4:f0
nfx:let_ring
wait:240
clean0:note:s4:f0
nfx:tie
wait:240
...
```
- new_measure: Means bar
- clean0: Guitar sound
- note:s4:f0: Note evnet on string 4 at fret 0
- nfx: play technique
- wait: duration in ticks (480 ticks = quarter note)
